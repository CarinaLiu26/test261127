# 禾煎訂單後端：Google 試算表 + Apps Script

網站結帳後，訂單會送到 Google Apps Script（GAS），由它寫進 Google 試算表並寄通知信。

```
網站結帳 ──POST──▶ GAS 網頁應用程式 (doPost)
                     ├─ 驗證欄位、擋機器人、限制同一電話下單次數
                     ├─ 用「商品」工作表的價格重新計價（不信任網站送來的金額）
                     ├─ 寫入「訂單」「訂單明細」
                     └─ 寄信給店家（與顧客確認信）
            ◀──JSON── { ok, orderId, total }
```

## 試算表會有四個工作表

| 工作表 | 內容 | 你可以做的事 |
|---|---|---|
| 訂單 | 一筆訂單一列：編號、時間、狀態、顧客、商品摘要、金額 | 用「狀態」下拉選單更新進度（新訂單 → 製作中 → 可取餐 / 已出貨 → 已完成 / 已取消），會自動上色 |
| 訂單明細 | 一個品項一列，方便做樞紐分析（哪個商品賣最好） | 不需手動修改 |
| 商品 | 商品 ID、品名、單價、單位、上架 | 改價格、把「上架」改成「否」即可停售。**改價時也要同步改網站上的價格** |
| 設定 | 通知信箱、宅配運費、免運門檻、接受訂單、寄送顧客確認信、下單上限 | 「接受訂單」改成「否」可暫停網站接單 |

## 安裝步驟（約 10 分鐘）

1. **建立試算表**：到 [Google 試算表](https://sheets.google.com) 新增空白試算表，命名為「禾煎訂單」。
2. **貼上程式**：選單「擴充功能 → Apps Script」。把編輯器裡預設的程式全部刪掉，貼上本資料夾的 `Code.gs` 全部內容，按「儲存」（磁碟圖示）。
3. **初始化**：回到試算表並重新整理頁面，上方會出現「禾煎訂單」選單 → 點「① 初始化工作表」。
   - 第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。這是因為程式是你自己寫的、尚未經 Google 審核，屬正常流程。
4. **確認設定**：打開「設定」工作表，確認「通知信箱」是要收訂單通知的信箱。可用選單「寄送測試通知信」測試。
5. **部署成網頁應用程式**：回到 Apps Script 編輯器，右上角「部署 → 新增部署作業」。
   - 類型：齒輪圖示 →「網頁應用程式」
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
   - 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
6. **測試網址**：用瀏覽器直接打開該網址，看到 `{"ok":true,"service":"hojian-orders",...}` 就代表成功。
7. **接上網站**：把網址填進 `index.html` 裡的 `const ORDER_API='';`（或把網址交給 Claude 幫你填）。填入後，結帳按鈕會變成「確認送出訂單」，訂單就會進到試算表。

## 選用功能

- **每日營收報表**：選單「開啟每日營收報表（每晚 9 點寄信）」。
- **今日營收摘要**：選單「今日營收摘要」，立即顯示今天訂單數與營收（不含已取消）。

## 之後修改程式

改完 `Code.gs` 後，要到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」，網站才會用到新程式。這樣做網址不會變。若改用「新增部署作業」，會產生新網址，需要重新填進網站。

## 注意事項

- **限制**：個人 Gmail 帳號每天約可寄 100 封信。店家通知與顧客確認信各算一封，訂單量大時可在「設定」關掉顧客確認信。GAS 單次執行約 1–3 秒，網站按鈕會顯示「送出中…」。
- **安全**：網頁應用程式網址寫在公開的網站上，任何人都能對它送資料。程式已經做了這些防護：
  - 欄位格式與長度檢查
  - 以試算表價格重新計價
  - 隱藏欄位擋機器人
  - 同一電話每小時下單上限
  - 防止以 `=` 開頭的公式注入

  但它無法驗證「真的是本人」。若遇到惡意大量下單，可先把「接受訂單」改成「否」。
- **付款**：目前只建立訂單、不處理線上付款（取餐或收貨時付款）。若要線上付款，需要串接金流服務（如綠界、藍新），那必須另外有後端伺服器。
